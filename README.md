# 🐾 Desktop Screen Pet

A charming, interactive desktop cat companion that roams your screen as an overlay above your open applications. Features real-time needs, affection tracking, customizable styles, and playful desktop mischief!

![Electron](https://img.shields.io/badge/Platform-Windows%20(Electron)-blue?style=flat-square)
![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)

---

## ✨ Features

- 🐱 **Always-On-Top Screen Overlay**: The cat wanders across your desktop over any window with transparent backgrounds.
- 🎨 **Customizable Pet**:
  - **Fur Patterns**: Ginger Tabby, Tuxedo, Calico, and Snow White.
  - **Accessories**: Bell Collar, Dapper Red Bowtie, Party/Wizard Hat, or Natural.
  - **Custom Name Tag**: Name your cat whatever you like!
- 🍖 **Real-Time Hunger System**: Needs to be fed 3 meals a day (Breakfast, Lunch, Dinner).
- 💖 **Love & Petting**: Click or stroke your cat with your cursor to shower it with affection, trigger sweet purrs, and burst heart particles.
- ⭐ **Friendship & Bonding**: Over time and daily care, your friendship level rises (unlocking cute titles from *Curious Stray* to *Soulmate Kitty*).
- 😼 **Playful Window Mischief**:
  - The cat can jump on active windows and minimize them!
  - The cat can grab the active window and drag it along as it walks!
  - *Includes a safety toggle in the widget so you can turn off mischief during serious work.*
- 📱 **Collapsible Corner Dock**: Stays quietly docked in the bottom-right corner. Can be collapsed into a tiny floating paw badge (`🐾`).
- 🛏️ **Snooze / Call**: Need full screen focus? Send the cat to bed, and call it back whenever you want company.
- 🎵 **Procedural Audio**: Crisp kitten meows, purrs, snack chomps, and leveling chimes generated in real-time via Web Audio API.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)

### Installation

```bash
# Clone the repository
git clone https://github.com/Sakura-619/desktop-pet.git

# Navigate into project directory
cd desktop-pet

# Install dependencies
npm install

# Run the app
npm start
```

## 🎮 Controls

| Action | How to Trigger |
| :--- | :--- |
| **Pet the Cat** | Left click or click the 💖 button in the widget |
| **Pick Up & Move Cat** | Click and drag the cat anywhere on your desktop |
| **Meow** | Double-click the cat |
| **Feed Cat** | Click the 🐟 Feed button in the corner widget |
| **Minimize Control Panel** | Click the `—` button in the widget header |
| **Expand Control Panel** | Click the floating `🐾` paw badge |
| **Toggle Mischief** | Use the toggle switch in the corner widget |
| **Test Mischief Now** | Click the `⚡` button next to the mischief toggle |
